# GA4 and Google Ads settings audit

Use for web and app measurement. For each relevant row record the exact setting/value, reason, and verification. Pick ON/OFF based on the user's objective and permission, regional rules, route eligibility and the source implementation. Verify the current UI and provider prerequisites.

| Setting | What to check or configure | Proof |
| --- | --- | --- |
| Property and stream | Match domain, hostname, package or bundle and production environment. Verify stream/tag IDs, reporting time zone and currency. Avoid a second property or stream without an explicit reason. | Source IDs and admin readback agree, with a genuine event in the intended stream. |
| Consent Mode and SDK defaults | Check analytics_storage, ad_storage, ad_user_data and ad_personalization individually. Ensure CMP or SDK defaults precede optional collection and updates follow actual choices. Forward applicable states to the server. | Fresh, accept, deny, partial, revoke, reload, and app account-switch checks. Inspect which signals were actually sent. |
| Google Ads product link and auto-tagging | Under GA4 Admin → Product links → Google Ads links, link the correct Ads customer to the property when in scope. Verify both sides, keep web auto-tagging ON and check real click-ID survival through redirects and handoffs. | Saved link, actual campaign route and trusted source fields. Flag broader manager-account linking effects. |
| Search Console product link | For owned websites, use GA4 Admin → Product links → Search Console links. Link the verified Search Console property covering the same pages to the correct GA4 web stream. Requires GA4 Editor and verified Search Console ownership. | Confirm the saved property/stream pair and organic-search reports when data is ready. |
| Google Signals | Under GA4 Admin → Data collection, turn ON for authorized, eligible demographics or remarketing. Review regional collection, applicable end-user consent and privacy disclosures. Recheck the forwarding implementation when using server GTM. | Property settings and regional readback, eligible reporting/audience evidence where available. |
| Enable Personalized Advertising | Inspect property/region restrictions and the individual Ads link. Enable only when authorized and eligible. Google documents at least one of Google Signals or user-provided data collection for GA4 remarketing. | Saved link plus intended audience export, exclusions, lookback and Ads membership/eligibility. |
| User-provided data collection | Evaluate for supported first-party matching goals. Check property, stream/tag, consent and policy acknowledgements. Prefer the narrow verified fields an eligible form or backend owns. Audit automatic collection before enabling it. | Confirm supported hashed fields appear in the appropriate channel and are absent on deny. Keep raw contacts and hashes out of ordinary GA4 parameters and public dataLayer. |
| Enhanced Measurement | Under GA4 Admin → Data streams, open the production web stream and turn Enhanced Measurement ON. Review page views/history, outbound links, scroll, site search, file downloads, form and video individually. Disable overlapping or unsafe automatic events as needed. Coordinate SPA views with custom routing. Use a confirmed successful form outcome for any lead used in bidding. | One expected event per interaction when an automatic and custom route could overlap. Inspect automatic URL/form fields for leakage. |
| Key events and Ads imports | Inventory the actual triggers, naming, source stream, conversion IDs, counting, currency/value and campaign goals. Avoid duplicate bidding across imported and direct actions. | DebugView or scoped test, processed GA4 event, Ads conversion readback and real attributed outcome when available. |
| Reporting dimensions and User-ID | Register only useful bounded dimensions, such as account role; reuse standard parameters. Use a permitted, opaque User-ID for signed-in journeys. Handle logout and account switching. | Correct values and scope in the report. Exclude contacts, persistent sensitive IDs and arbitrary high-cardinality values. |
| Cross-domain and referrals | For owned linked domains, verify linker and click context continuity. Check intermediary/payment referrals when relevant and confirm campaign source survives a real return. | Same intended journey and acquisition source across the documented flow. |
| Granular location and device | Inspect collection by region and collect only the detail the project needs. For Measurement Protocol consider inherited context or a permitted structured location. | Expected geography/device data and saved regional settings. Keep IP out of general events and reports. |
| Retention, filters and export | Under GA4 Admin → Data retention, change **2 months to 14 months** on standard GA4 when authorized and consistent with the project's retention policy. Verify after saving. This primarily affects user/event-level data for Explorations and funnel reports. Audience membership and aggregate reports have separate rules. Test internal, development or hostname filters before activation. Audit intended BigQuery or product links, access and data scope if used. | Saved retention, sample filter readback, correct export destination and access. Active GA4 exclusion can discard future events permanently. |

## Best data to Google

Verify the GA4 ↔ Google Ads product link and the [Data Manager API offline upload](conversion-routes.md#google-offline-conversions-and-first-party-matching) independently. Linking enables supported GA4/Ads imports and audience sharing. A Data Manager API upload targets a Google Ads conversion action directly.

Use real click/attribution context, stable conversion IDs, approved value/currency, reliable triggers, correct campaign goals, and eligible first-party match fields. Distinguish GA4 user-provided data, Ads enhanced conversions, and Measurement Protocol; each has its own prerequisites and purpose. Google Signals, consent choices, personalized advertising, and audience population are separate observations. Keep unnecessary data collection off.
